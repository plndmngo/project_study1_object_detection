## Pocket Ledger (finance-tracker/)

A phone-friendly personal finance tracker: log income and expenses, see a monthly
summary, spending by category, a 6-month trend, and per-category budgets.

- `finance-tracker/app.html` is the source; `./finance-tracker/build.sh` regenerates
  `finance-tracker/index.html`, a standalone page you can host anywhere (e.g. GitHub Pages).
- Open `index.html` on your phone and use "Add to Home Screen" to install it like an app.
- In the standalone version, data is stored in your browser (localStorage) on that device.
  Use Budgets → "Export all transactions (CSV)" to back it up.
